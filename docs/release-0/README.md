# Release 0 evidence

Release-0-specific deliverables and evidence, per the project spec's
Release 0 submission requirements: implementation summary, local testing
evidence, GitHub Actions workflow execution evidence, Docker Compose
execution evidence, screenshots of the integrated application, known
issues/limitations, contribution logs, GitHub commit logs, and attendance
checkpoints.

Currently in this folder:

- `student-3-agentic-loop-evidence.md` — Student 3's write-up of adding
  shared-authentication support, framed as a Plan/Act/Observe/Adapt
  development log. Note: this documents the *development process* for
  that feature, not the running application performing its own
  Plan → Act → Observe → Adapt reasoning loop at runtime. The project spec's
  section 4.3 ("Shared Team Agentic Loop") and section 2.2 (individual
  responsibility to "demonstrate the Plan → Act → Observe → Adapt Agentic
  AI workflow") are asking for the latter — an AI feature in the app that
  itself plans, acts, observes, and adapts (see `student-1-budget/backend/agent.py`
  for the one implementation in this repo that actually does this). This
  file is still useful evidence of AI-assisted development, but it should
  not be submitted as the team's agentic-loop implementation evidence on
  its own.
- `student-3-ai-prompts.md` — Student 3's AI-assisted development prompt log.
- `student-3-showcase-checklist.md` — Student 3's showcase prep checklist.
